# primeiros-passos-js
Primeiros passos com JavaScript: comandos de interação no navegador (alert, prompt e confirm) integrados com HTML5 e CSS3.

# Primeiros Passos com JavaScript 🚀

Projeto desenvolvido durante meus estudos de Front-End para praticar os primeiros comandos de interação no navegador usando JavaScript (`window.alert`, `window.prompt` e `window.confirm`) integrados a uma página HTML5 estilizada com CSS3.

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript

## 📌 Aprendizados
- Execução sequencial de scripts JS no navegador
- Métodos globais de diálogo (`alert`, `prompt`, `confirm`)
- Estilização básica com CSS (`font-size`, `background-color`, alinhamento)
